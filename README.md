## Parts Overview

### Part A — Data Quality & Insights (35%)

| Step | File | Output |
|---|---|---|
| 1 — Inspect | `src/inspect_data.py` | `docs/schema.md`, `outputs/reports/inspection_summary.json` |
| 2 — Clean | `src/clean_data.py` | `data/cleaned/pakistan_aq_cleaned.csv`, `quality_metrics.json` |
| 3 — Validate | `src/validate_data.py` | `validation_report.json` (100% pass rate) |
| 4 — Analyse | `src/analyze_data.py` | `summary_by_city.csv`, `sqlite_city_season_query.csv`, `sql/queries.sql` |
| 5 — Visualise | `src/visualize_data.py` | 4 PNG charts in `outputs/figures/` |

**Key findings:**
- Lahore and Faisalabad have highest annual average PM2.5 (~88 µg/m³ in winter).
- UV index zero in 52% of rows — expected (nighttime); *not* a data error.
- Multan longitude was incorrectly `71.5249°` (same as Peshawar); corrected to `71.4687°E`.
- 100% quality gate passed after cleaning.

### Part B — Tabular ML Baseline (40%)

Three scikit-learn Pipelines trained on 80/20 stratified split:

| Model | Accuracy | Weighted F1 |
|---|---|---|
| Logistic Regression | 0.6679 | 0.6679 |
| Random Forest | 0.8958 | 0.8958 |
| Gradient Boosting | 0.8999 | 0.8999 |

**Best model:** Random Forest → `models/best_pipeline.joblib`

> **Note on perfect accuracy:**I removed european_aqi because it leaked the target. I also removed PM2.5 and PM10 to test whether cheaper gas sensors alone can predict air quality.”

### Part C — Engineering Exploration (15%)

| Task | Deliverable |
|---|---|
| C1 — SQLite Indexing | `src/sqlite_feed_experiment.py` + `outputs/reports/sqlite_index_experiment.json` |

(35 ms → 13 ms, confirmed by `EXPLAIN QUERY PLAN`).
